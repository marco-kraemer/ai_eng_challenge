# 11 — Preparar e copiar resposta para o cliente com evidências

**O que construir:**
A partir de uma orientação baseada em fontes, permitir preparar uma mensagem curta para encaminhar ao cliente. Separar visualmente orientação do atendimento, rascunho e evidências; copiar exige clique explícito, sem enviar mensagens para serviços externos.

**Bloqueado por:**
- 10
- 03

**Status:** ready-for-agent

## Critérios de Aceitação
- [ ] O rascunho usa somente fatos do atendimento atual e mantém limites e conflitos relevantes.
- [ ] Copiar funciona com feedback acessível e apresenta alternativa selecionável se a área de transferência falhar.
- [ ] Nenhuma mensagem é enviada automaticamente; testes verificam preservação das fontes e fluxo de cópia.
